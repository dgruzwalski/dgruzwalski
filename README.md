* **Tech Stack:** MATLAB, Simulink, Frequency Response Analysis, LabVIEW.
* **Key Achievement:** Conducted sensitivity studies on manufacturing, design, and uncontrollable parameters, and validated analytical predictions using physical test rigs and commercial simulation software.
